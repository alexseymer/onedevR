# Get a single build by UI number

Get a single build by UI number

## Usage

``` r
od_get_build(build_number, conn = NULL, use_internal_id = FALSE)
```

## Arguments

- build_number:

  character\|numeric UI number (`100` or `"#100"`).

- conn:

  list Connection list from
  [`od_get_config()`](https://alexseymer.github.io/onedevR/reference/od_get_config.md)
  /
  [`od_connection()`](https://alexseymer.github.io/onedevR/reference/od_connection.md).
  Default: `NULL`.

- use_internal_id:

  logical If `TRUE`, treat `build_number` as the internal REST id
  (debugging only). Default: `FALSE`.

## Value

list Parsed build object.
