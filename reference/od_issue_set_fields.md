# Set custom issue fields

Set custom issue fields

## Usage

``` r
od_issue_set_fields(issue_number, fields, conn = NULL)
```

## Arguments

- issue_number:

  character\|numeric UI number.

- fields:

  list Named list of field values (installation-specific schema).

- conn:

  list Connection list. Default: `NULL`.

## Value

list Parsed API response.
