# List group members

Retrieves all members of a user group.

## Usage

``` r
od_list_group_members(group_name, as_tibble = NULL, conn = NULL)
```

## Arguments

- group_name:

  character Name of the group.

- as_tibble:

  logical If `TRUE` (default via `options(onedevr.as_tibble)`), return a
  tibble via
  [`od_as_tibble()`](https://alexseymer.github.io/onedevR/reference/od_as_tibble.md).
  Default: `NULL`.

- conn:

  list Connection list from
  [`od_get_config()`](https://alexseymer.github.io/onedevR/reference/od_get_config.md)
  /
  [`od_connection()`](https://alexseymer.github.io/onedevR/reference/od_connection.md).
  Default: `NULL`.

## Value

tibble\|list A tibble of group members (default), or a list when
`as_tibble = FALSE`.
