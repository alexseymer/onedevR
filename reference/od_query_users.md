# Query OneDev users

Calls `GET /users`.

## Usage

``` r
od_query_users(
  query = NULL,
  count = 100L,
  offset = 0L,
  as_tibble = NULL,
  conn = NULL
)
```

## Arguments

- query:

  character Optional OneDev user query string. Default: `NULL`.

- count:

  integer Maximum number of results (default `100`).

- offset:

  integer Result offset (default `0`).

- as_tibble:

  logical If `TRUE` (default via `options(onedevr.as_tibble)`), return a
  tibble via
  [`od_as_tibble()`](https://alexseymer.github.io/onedevR/reference/od_as_tibble.md).
  Default: `NULL`.

- conn:

  list Connection list from
  [`od_get_config()`](https://alexseymer.github.io/onedevR/reference/od_get_config.md)
  /
  [`od_connection()`](https://alexseymer.github.io/onedevR/reference/od_connection.md).
  Default: `NULL`.

## Value

tibble\|list A tibble of users (default), or a list when
`as_tibble = FALSE`.
