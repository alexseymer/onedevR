# Get a single project

Get a single project

## Usage

``` r
od_get_project(project = NULL, conn = NULL)
```

## Arguments

- project:

  character\|numeric Project path (e.g. `"group/my-project"`) or numeric
  id. Defaults to the connection project. Default: `NULL`.

- conn:

  list Connection list from
  [`od_get_config()`](https://alexseymer.github.io/onedevR/reference/od_get_config.md)
  /
  [`od_connection()`](https://alexseymer.github.io/onedevR/reference/od_connection.md).
  Default: `NULL`.

## Value

list Parsed project object.
