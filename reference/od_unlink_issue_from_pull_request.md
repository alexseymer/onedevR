# Remove a link between an issue and a pull request

Removes the link between an issue and a pull request.

## Usage

``` r
od_unlink_issue_from_pull_request(
  issue_number,
  pull_request_number,
  conn = NULL
)
```

## Arguments

- issue_number:

  character\|numeric UI issue number (`145` or `"#145"`).

- pull_request_number:

  character\|numeric UI pull request number (`42` or `"#42"`).

- conn:

  list Connection list from
  [`od_get_config()`](https://alexseymer.github.io/onedevR/reference/od_get_config.md)
  /
  [`od_connection()`](https://alexseymer.github.io/onedevR/reference/od_connection.md).
  Default: `NULL`.

## Value

list Parsed API response.
