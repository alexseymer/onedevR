# Login name of the current user

Returns the login name to use for "me", for example as the value of an
`Assignee` field. It asks `GET /users/me`; if the server answers 401,
403 or 404 for that endpoint (some tokens cannot call it), it falls back
to the `username` of the connection (`ONEDEV_USERNAME`). Other errors,
such as network failures, are not hidden.

## Usage

``` r
od_whoami(conn = NULL)
```

## Arguments

- conn:

  list Connection list from
  [`od_get_config()`](https://alexseymer.github.io/onedevR/reference/od_get_config.md)
  /
  [`od_connection()`](https://alexseymer.github.io/onedevR/reference/od_connection.md).
  Default: `NULL`.

## Value

character Login name.

## Details

A username does not change the auth mode when `auth` is set explicitly.
To keep token (Bearer) auth and still provide a name, set
`ONEDEV_AUTH=bearer` together with `ONEDEV_USERNAME`, or pass
`auth = "bearer"` and `username` to
[`od_connection()`](https://alexseymer.github.io/onedevR/reference/od_connection.md).
